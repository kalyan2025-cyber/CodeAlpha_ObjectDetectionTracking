# Object Detection and Tracking

## Description

Object Detection project built using YOLOv8 and OpenCV.

## Features

* Detect Objects in Images
* Bounding Boxes
* Object Classification
* Real-time Detection Support

## Technologies Used

* Python
* YOLOv8
* Ultralytics
* OpenCV
* Streamlit

## Run the Project

pip install -r requirements.txt

streamlit run app.py
